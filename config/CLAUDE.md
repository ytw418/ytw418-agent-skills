## 모델 분업·토큰 절약
- 도구 한 번마다 대화 전체가 다시 읽힌다. 왕복과 쌓이는 양이 곧 비용이다.
- 쉬운·반복 작업이면 첫 줄에 "`/model sonnet` 이나 `/effort low` 로 충분합니다"라고 알리고 진행한다.
- 판단이 막힐 때만 그 판단을 `Agent(model: "fable")` 에 좁혀서 맡기고 기다린다(설계만, 구현은 메인).
- 위치를 모르고 파일 3개 이상 훑을 땐 `Agent(subagent_type: "Explore", model: "haiku")`. 아는 파일 1~2개는 직접 읽는다. 서브에이전트 `model` 을 비우지 않는다.
- 여러 파일 흐름은 `graphify query/explain/path` 부터.
- 질문 하나에 주간 한도 20% 이하(훅 `usage-budget.py`가 막으면 한 것·남은 일·줄일 방법을 보고하고 멈춘다). 큰 작업은 시작 전에 범위·예상 사용량을 말한다. 긴 대화가 끝나면 `/compact` 나 `/clear` 를 권한다.

## 로컬 CPU·메모리 보호 (MANDATORY)
- 빌드·전체 테스트·Metro·에뮬레이터는 컴퓨터 전체에서 한 번에 하나(끝난 걸 확인한 뒤 다음). 렉·메모리 부족이면 안 쓰는 에뮬레이터·브라우저 탭·개발 서버부터 끄고 이어 간다(보안 프로그램·사용 중인 앱 금지, `pkill node`·`killall` 금지).
- 작은 UI 변경은 관련 lint·테스트·화면 확인만. Jest `--runInBand`, Metro `--max-workers 2`. UI 작업에서 DB 명령 금지. 띄운 프로세스는 끝나면 직접 끈다.
