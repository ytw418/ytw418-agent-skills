# PR 본문 템플릿 (bredy-pr-loop 10절)

웹 PR 하나에 앱 캡처까지 넣는다. 앱 PR 본문은 짧게(개요 + 웹 PR 링크 + 테스트)만 쓴다.
맨 위 두 줄은 세션이 준 프로젝트 귀속 줄(있을 때만)이다.

```markdown
<!-- 세션 귀속 두 줄 -->

## 개요
- 왜: <사용자 문제 한 줄>
- 기획: <PRD 경로> · 시안: <시안 경로>

## 주요 변경
- 서버: …
- 웹: …
- 앱: … (짝 PR ytw418/bredy_app#<번호>)

## 테스트
- 정적: verify:ci 통과 (<sha7>) · 앱 tsc·lint·check:colors 통과
- e2e(웹, 로컬 next dev 390×844): <시나리오> → 통과
- e2e(앱, 에뮬레이터 bredy_qa): <시나리오> → 통과
- 독립 리뷰: <n>건 중 <m>건 수정, 나머지 근거 남김
- dev 테스트 데이터: <모델 id 목록> (정리 여부)

## 스크린샷
| 화면 | 앱 | 웹 |
|---|---|---|
| <화면> | <img …> | <img …> |

## 캐시·폴링   <!-- 새 페이지·API 가 있을 때만 -->
- 공개/개인 · 쪽 수 · 바뀌는 빈도 · 렌더링·캐시 시간·태그 · 비우는 쓰기 · 폴링 간격

dev DB 마이그레이션 적용 — <이름들>   <!-- 마이그레이션이 있을 때만 -->

Parity: both — ytw418/bredy_app#<번호>
```
