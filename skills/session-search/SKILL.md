# Session Search

Claude Code는 모든 세션을 `~/.claude/projects/<프로젝트슬러그>/*.jsonl`에 남긴다. 지금 대화에 없는 과거 맥락은 여기에만 있다.

## 사용법

```bash
python3 scripts/search.py "<정규식>" [옵션]
```

| 옵션 | 기본 | 용도 |
|---|---|---|
| `--days N` | 90 | 검색 기간 |
| `--role user\|assistant\|any` | any | 발화 주체 필터 |
| `--max N` | 25 | 결과 상한 |
| `--project <문자열>` | — | 프로젝트 디렉토리명 부분 일치 |
| `--files-only` | — | 세션 파일 경로만 출력 |

## 검색 전략

**좁은 패턴부터 시작한다.** 세션 로그에는 파일 내용·명령 출력·도구 입력이 통째로 들어 있어, 흔한 단어는 수백 건이 걸린다. 고유한 것(티켓 키 `CQA-799`, 함수명, 에러 메시지 원문, 브랜치명)으로 먼저 좁힌다.

**결과가 너무 많으면** `--max`를 늘리지 말고 패턴을 좁히거나 `--role user`로 사용자 발화만 본다. 사용자 발화는 그 세션에서 무엇을 하려 했는지를 가장 압축적으로 담고 있다.

**결과가 0건이면** 기간(`--days`)을 먼저 의심한다. 기본 90일 밖일 수 있다.

## 결과를 읽은 다음

스니펫은 220자로 잘려 있다. 맥락이 더 필요하면 출력된 `.jsonl` 경로를 직접 열되, **파일 전체를 Read하지 마라** — 세션 하나가 수십 MB일 수 있다. `grep -n`으로 위치를 잡고 `sed -n 'N,Mp'`로 해당 구간만 본다.

```bash
grep -n "<패턴>" <세션.jsonl> | head
sed -n '120,140p' <세션.jsonl>
```

## 주의

- 검색 대상은 **로컬 기록뿐**이다. 다른 머신이나 클라우드 세션은 잡히지 않는다.
- `subagents/` 하위 파일도 포함된다 — 서브에이전트가 한 작업도 검색된다.
- 읽기 전용이다. 세션 기록을 수정하거나 지우지 않는다.
