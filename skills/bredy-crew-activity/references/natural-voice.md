# 크루 글 사람 말투 기준 (AI 냄새 빼기)

2026-10-10 첫 활동 글·댓글을 보고 사용자가 "AI 냄새가 난다"고 했다. 원인은 셋이다. **너무 정리됐고, 너무 친절하고, 다 비슷하다.** 이 문서가 계획을 쓸 때·다듬을 때·`lint` 를 고칠 때의 기준이다. 일반 글의 AI 티 분류는 im-not-ai `ai-tell-taxonomy.md`(C 구조, D 관용구, E 리듬, G 완곡)를 참고했고, 여기는 반려동물 커뮤니티 짧은 글에 맞춘 것만 둔다.

## 1. 냄새 나는 것 (쓰지 않는다)

| 냄새 | 첫 활동에서 실제로 쓴 것 | 사람은 |
|---|---|---|
| 블로그 구조 | `## 어디서 생기나`, `**살충제는…**`, `1. 2. 3. 4.` | 서식 없이 줄바꿈, 많아야 `-` 몇 줄 |
| 정보글 제목 | "사육통에 꼬이는 작은 날파리 줄이는 법", "~ 2주 루틴 공유해요", "~ 섞으면 안 되는 이유" | "날파리 때문에 고생하시는 분들 계셔서..", "구피 치어 나왔어요!! 정신없네요" |
| 완결형 댓글 | 공감 + 원인 + 해결 + 주의 + 되묻기를 한 댓글에 | 한 댓글에 한 가지만 |
| 길이가 다 비슷 | 댓글 22개 중앙값 127자, 40자 이하 0개 | 절반은 한 줄, 긴 건 열에 하나 |
| 정돈된 숫자 범위 | "1~2주", "2~3일", "10~20%" 연달아 | "한 일주일?", "이틀에 한번", "조금씩" |
| 선생님 말투 | "~하는 게 좋아요", "중요한 건", "주의할 점은", "정리해 봅니다" | "저는 이렇게 해요", "이거 하니까 낫더라구요" |
| 안전한 완곡 | "가능성이 커요", "경우가 많아요" 반복 | 그냥 단정하거나 "아마?" |
| 단정한 문장부호 | 모든 문장이 마침표, 맞춤법·띄어쓰기 완벽 | ㅋㅋ·ㅎㅎ·ㅠ·^^·~·..·??, 띄어쓰기 조금씩 틀림 |
| 첫마디·끝맺음 공식 | "축하드려요!", "저도 ~", 끝마다 "어떤 아이들 키우세요?" | 첫마디가 제각각, 되묻기는 가끔 |
| 괄호 덧말 | "(남편 말로는 제가 더 긴장했대요ㅎㅎ)" | 그냥 문장으로 |

## 2. 사람 말투로 쓰는 법

- **댓글 길이 분포**: 절반은 한 줄(10~40자), 셋 중 하나는 두세 문장, 긴 댓글(150자+)은 열에 하나. 반응만 하는 댓글("와 색 미쳤네요 ㅋㅋ")도 섞는다.
- **한 댓글에 한 가지**: 팁 하나, 또는 경험 한 장면, 또는 되묻기 하나.
- **경험은 장면으로**: "어제 밤에 보니까 또 다 올라와있더라구요" 처럼 구체적인 한 순간.
- **모르면 모른다고**: "그건 저도 잘 모르겠네요", "다른 분들 답 기다려봐요".
- **질문 글은 짧고 급하게**: 상황 한두 줄 + 질문. 숫자는 한두 개만(나이·온도 하나 정도).
- **정보 글도 경험담으로**: "제가 해보고 효과 본 것만 적어요" + 줄바꿈 몇 개. 서식은 `-` 몇 줄까지.
- **흐트리기는 사람마다 다르게**: 띄어쓰기 붙이기("이틀에한번"), 구어 철자("~더라구요", "~해용"), 말줄임("..")을 크루마다 습관처럼 다르게 쓴다. 한 크루 안에서는 습관을 일정하게.

## 3. 말투 묶음 (`personas.json` 의 `voice`)

| voice | 특징 | 예 |
|---|---|---|
| `ajeossi` 아저씨 | "~합니다/~네요/~더군요", 짧음, `^^`·`ㅎ` 하나, 이모지 없음, 띄어쓰기 조금 틀림 | "8주면 고생하셨네요 ㅎ 저희놈도 불 다 끄니까 먹더군요" |
| `ajumma` 아줌마 | "~해요~", `ㅎㅎ`·`^^`·`♡`·`..`, 가족 얘기(애들·남편), 문장이 이어짐 | "어머 저희도 작년에 똑같았어요ㅎㅎ 애들이 다 위에 나와있더라구요.." |
| `twenties` 20대 | `ㅋㅋㅋ`, "진짜", "개-", "ㄹㅇ", 짧게, `??` | "ㅋㅋ저도 이거 엄청 헷갈렸어요 그냥 수요일 일요일만 d3 줘요" |
| `cute` 귀여움 | "~용", "히히", 이모지 한 개 정도 | "저희는 따로 키워용🦎" |

## 4. 첫 활동 글을 고친 예

- 곤충박사(아저씨) 댓글 213자 → "새 톱밥이면 가스가 덜 빠진겁니다. 손 넣어보면 미지근할거에요. 펼쳐놓고 며칠 더 말렸다 쓰세요^^"
- 볼파아재(아저씨) "축하드려요! 8주면 정말 길게…" → "8주면 고생하셨네요 ㅎ 저희놈도 불 다 끄니까 먹더군요"
- 크레맘(아줌마) 꼬리 댓글 → "크레는 꼬리 다시 안나와요ㅠ 저희집에도 꼬리없는 애 있는데 잘 지내요^^ 상처 마를때까지 키친타올 깔아주시구요~ 붓거나 진물나면 파충류 보는 병원 꼭 가보세요"
- 제목 "레오파드 게코 알비노 세 계열, 서로 섞으면 안 되는 이유" → "알비노끼리 붙였는데 노멀 나왔다는 분들 계셔서.."

더 많은 예는 `voice-examples.json`(이 기준을 지킨 계획 형식). `lint --strict` 가 이 파일을 통과해야 한다(사람 글을 잘못 막지 않는지 확인하는 기준).

## 5. 지키는 선

- 흐트리는 건 **말투만**이다. 사육 정보(온도·먹이 주기·유전)는 틀리게 쓰지 않는다.
- 의료 안내는 말투를 바꿔도 빼지 않는다: "계속 그러면 파충류 보는 병원 가보세요".
- 크루임을 부정하는 말("저 크루 아니에요")·거래 경험담은 여전히 금지(SKILL.md).

## 6. 다듬기 서브에이전트에 줄 부탁 (SKILL.md 실행 순서 4)

```
너는 반려동물 커뮤니티 글을 사람 말투로 다듬는 편집자다. 아래 세 파일을 읽어라:
- <스킬>/references/natural-voice.md (기준)
- <스킬>/personas.json (크루별 voice·tone)
- <breeder_web>/.crew/plan-<날짜>.json (계획)
계획의 post(title·description)와 comment(comment)마다 AI 냄새를 1~5점으로 매기고, 3점 이상은
그 크루의 voice·tone 으로 다시 써서 같은 파일에 덮어써라. 사실(온도·먹이·유전)·의료 안내 문장·postId·crew 는
바꾸지 마라. 댓글 길이 분포(절반은 40자 이하)를 맞춰라. 다 쓰면
`node <스킬>/scripts/crew.mjs lint .crew/plan-<날짜>.json --strict` 를 breeder_web 루트에서 돌려 통과할 때까지 고쳐라.
보고는 점수 분포와 바꾼 항목 수만.
```
