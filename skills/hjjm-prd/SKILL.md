# HJJM PRD

HJJM 하네스는 "PRD는 동작 의도, .pen 디자인은 시각 의도"를 입력 계약으로 받아
이슈 DAG → 병렬 Builder → 플랫폼 Verifier → 실행 원장 Done 순서로 제품을 만든다.
이 스킬은 그 하네스가 그대로 먹을 수 있는 PRD를 만든다. 하네스 구조와 Done 규칙은
[references/hjjm-harness.md](references/hjjm-harness.md)를 읽는다(처음 쓰거나 설명을 요구받으면 반드시 읽는다).

## 원칙

- **판정 가능해야 문서다.** 모든 수용 기준은 "예/아니오"로 답할 수 있어야 하고, 검사 명령 또는 검사 절차가 붙어야 한다. "빠르게", "자연스럽게" 같은 형용사만 있는 기준은 쓰지 않는다.
- **화면은 상태 단위로 적는다.** 화면마다 기본/로딩/빈/오류/권한없음 상태를 빠짐없이 적고, 디자인 프레임(.pen 또는 Figma 노드)과 연결한다. 상태가 없으면 "해당 없음"이라고 명시한다.
- **입력 식별값을 고정한다.** PRD id·버전, 디자인 파일 참조(경로/해시 또는 Figma 노드 id), 기준 SHA를 문서 상단에 적는다. 하네스는 이 값으로 모든 시도·후보·검사를 추적한다.
- **이슈는 파일 담당자가 한 명이다.** 같은 파일을 두 이슈가 건드리면 DAG에서 직렬화하거나 이슈를 합친다.
- **모르는 값은 지어내지 않는다.** "미결" 섹션에 질문으로 남긴다.

## 작업 순서

1. **입력 수집.** 사용자가 준 기능 설명, 디자인(.pen/Figma), 기존 코드·API를 읽는다. 코드베이스가 있으면 관련 화면·API·타입 파일 경로를 확인해 이슈의 "담당 파일"을 실제 경로로 적는다. 파일 3개 이상 훑어야 하면 Explore 서브에이전트에 맡긴다.
2. **빠진 정보 질문.** 사용자·기능·화면·오류·기준 중 비어 있는 것만 한 번에 묻는다. 답이 없으면 가정을 적고 "미결"에 남긴 채 진행한다.
3. **템플릿으로 작성.** [assets/prd-template.md](assets/prd-template.md)를 그대로 복사해 채운다. 섹션을 빼거나 순서를 바꾸지 않는다. 산출 경로 기본값은 `docs/prd/<prd_id>.md`.
4. **검증.** `python3 scripts/validate_prd.py <파일>`을 실행해 필수 섹션, AC의 판정 형식, 이슈의 담당 파일 중복, 추적표 누락을 잡는다. 통과할 때까지 고친다.
5. **보고.** 미결 질문과 가정을 먼저 보여주고, 이슈 DAG 요약(웨이브별 병렬 이슈)을 표로 준다.
6. **(선택) 실행.** 사용자가 "하네스 돌려", "실행해", "빌드해"라고 하면 [assets/harness-workflow.js](assets/harness-workflow.js)를 Workflow 도구에 `args: {prdPath, baseSha, startedAt}`로 넘겨 실행한다. Workflow 도구는 사용자의 명시적 요청이 있을 때만 호출한다.

## 작성 규칙 요약

| 항목 | 규칙 |
|---|---|
| ID | 기능 `F-n`, 화면 `S-n`, 상태 `S-n.<상태>`, 오류 `E-n`, 수용 기준 `AC-n`, 이슈 `I-n`, 검사 `V-n` |
| 수용 기준 | `조건 → 기대 결과` 한 문장 + 판정 `예/아니오` + 검사 방법(`V-n` 또는 명령) + 자동/수동 |
| 화면 상태 | 기본·로딩·빈·오류·권한없음 5종 필수. 없으면 "해당 없음" |
| 이슈 유형 | 공통 계약(모델/API/스키마) → 화면 구현 · 업무 기능 · 데이터 연동 → 통합 후보 QC/QA 순 |
| 이슈 필드 | 유형, 담당 파일(중복 금지), 의존 이슈, 필수 검사, 완료 정의(AC 목록) |
| Done 게이트 | 빌드 통과, 단위 coverage 80% 이상, 필수 테스트 전부 통과, E2E 자체 재시도 0회, 접근성 serious/critical 0건, 보안 high/critical/secret 0건, 기획·디자인 대조 통과, 독립 검토 통과 |

작성 예시는 [references/example-bredy.md](references/example-bredy.md)(브리디 앱 커뮤니티 신고/차단 서버화)를 참고한다.
