# 브리디 매체·제휴 소개 킷 (`bredy-press-kit`)

외부 매거진·미디어나 제휴처 담당자에게 전달할 브리디 공식 소개 문서와 고화질 이미지 패키지를 생성하고, 회신 메시지 작성 및 이메일 세팅·발송까지 수행한다.

## 핵심 규칙 (반드시 준수)

1. **결과물은 저장소 밖에 생성 (`CLAUDE.md` §16):**
   - 모든 캡처·렌더링·PDF·ZIP은 `~/bredy-media/marketing/<YYYY-MM-DD>-<slug>-kit/` 에 만든다. 저장소 안에 이미지를 만들지 않는다.
   - 패키징 후 임시 파일(`raw/`, `_*.html`)은 즉시 지운다.
2. **상대 매체 독자층에 맞춘 포지셔닝 (`bredy-marketing/docs/facts-and-rules.md`):**
   - **댕냥이·일반 반려동물 매거진 (기본값, 예: 펫집):** 강아지·고양이 개인 분양 홍보 문구는 쓰지 않는다(동물보호법 온라인 판매 광고 규제). 대신 **'입양부터 일상, 이별 뒤 기억까지'** 흐름(① 전국 보호소 입양·임보 공고 모아보기 ② 3D 무지개 마을 무료 추모관 ③ 우리 아이 타로카드 & 멍냥 월드컵 ④ 관심 동물 맞춤 커뮤니티)을 중심에 둔다.
   - **파충류·물생활·특수동물 매체:** 무료 분양글 등록, 30초 경매 링크(마감 직전 자동 연장), 혈통카드·출처 카드, 종별 사육 가이드를 중심에 둔다(곤충 확대 사진은 표지에 쓰지 않는다).
   - **추모·펫로스·유기동물 구조 단체:** 3D 무지개 마을(`?side=rainbow`, 추모관·꽃·밤 등불)과 보호소 공고 모아보기·'가족 찾아요' 무료 공유 카드 생성을 중심에 둔다.
3. **실제 운영 화면 검증 및 개인정보 보호:**
   - 문서에 적는 모든 링크는 현재 운영(`https://bredy.app`)에서 200으로 열리는지 확인한다(예: 무지개 마을 본화면은 `https://bredy.app/village/memorial?side=rainbow`, 타로는 `/fun/tarot`, 월드컵은 `/cute`).
   - 일반 회원의 반려동물 사진·닉네임·연락처가 보이는 영역(예: 무지개 마을 하단 '별이 된 친구들' 원형 사진 줄)은 반드시 크롭해서 제외한다.
4. **디자인·조판 검수 (`Read` 도구로 전수 확인):**
   - 4:5 카드뉴스(1080×1350): 인스타 프로필 그리드(3:4) 안전 영역(**좌우 96px, 상하 150px 안쪽**)에 모든 제목·로고·문구를 배치한다. 눌리지 않는 가짜 CTA 버튼 모양은 넣지 않는다.
   - 소개서 PDF: A4 **정확히 2쪽**에 빈 페이지나 1줄 넘침 없이 들어갔는지 렌더링된 PDF를 열어 모든 페이지를 눈으로 확인한다.
5. **이메일 준비 vs 발송 구분 (`CLAUDE.md` §9.1):**
   - 브리디 자동화 크롬(`127.0.0.1:9222`, 자기 탭만 열고 닫음)의 로그인된 메일(네이버 메일 `bredy_team@naver.com` / `ytw418@naver.com` 또는 Gmail)을 사용한다.
   - 사용자가 **"보낼 수 있게 준비해줘"**라고 하면 수신처·제목·본문·첨부파일까지 채워 **임시저장**만 하고 발송하지 않는다.
   - 사용자가 **"여기에 이메일 보내줘" / "발송해"**라고 명시 지시했을 때만 발송 버튼을 누르고, **보낸편지함**에서 실제 발송 시각·첨부 파일명을 확인해 보고한다.

## 실행 절차

### 1단계: 상대 매체 파악
- 사용자가 전달받은 메시지·이미지와 매체 홈페이지/인스타/리틀리를 확인해 **매체명, 구독자 성격, 공식 이메일 주소**를 파악한다.

### 2단계: 소개 킷 일괄 생성
번들 스크립트 `scripts/build-press-kit.mjs` 를 실행해 한국어 실제 화면 캡처 → 안전 크롭 → 4:5 카드 5장 + 1200×630 배너 → A4 2쪽 PDF → 복붙용 TXT → `.zip` 패키징까지 한 번에 만든다.

```bash
node ~/.agents/skills/bredy-press-kit/scripts/build-press-kit.mjs \
  --partner "펫집(petzip)" \
  --slug "petzip"
```

출력 구조 (`~/bredy-media/marketing/<YYYY-MM-DD>-<slug>-kit/`):
- `브리디_소개자료.pdf` (A4 2쪽 프레스킷)
- `브리디_소개자료_복붙용.txt` / `브리디_소개자료.md` (에디터 복사용 원고 및 캡션 예시 2종)
- `01_카드뉴스용_소개이미지_4x5/` (`01`~`05` PNG 5장, 1080×1350)
- `02_편집용_원본화면_및_로고/` (`logo_icon_512.png`, `banner_1200x630.png`, `screen_01`~`screen_07` PNG)
- 상위 폴더 `브리디_<매체명>전달용_자료모음.zip`

파충류·특수동물 중심 매체여서 슬라이드 구성을 바꿔야 하면 스크립트를 작업 폴더로 복사해 문구·캡처 URL만 수정한 뒤 실행한다.

### 3단계: 시각 검수 (생략 금지)
- 생성된 카드 5장, 가로 배너, 크롭된 원본 화면, `브리디_소개자료.pdf` 전체 페이지를 `Read` 로 열어 **글자 잘림·겹침·빈 페이지·회원 정보 노출이 0건**인지 확인한다.

### 4단계: 이메일 세팅 또는 발송
- 첨부 파일: `브리디_소개자료.pdf` (바로 열어보기용, 약 2MB) + `브리디_<매체명>전달용_자료모음.zip` (원본·카드뉴스 전체 묶음, 약 6MB) 두 개를 함께 첨부한다(네이버 메일 일반 첨부 10MB 한도 안).
- **브리디 자동화 크롬(9222) 네이버 메일(`https://mail.naver.com/v2/new`) 조작 규칙:**
  1. `http://127.0.0.1:9222/json/list` 에 열린 `page` 탭이 0개면 `connectOverCDP` 가 실패하므로 `curl -s -X PUT "http://127.0.0.1:9222/json/new?about:blank"` 로 기본 탭 1개를 먼저 확보한 뒤 `bchrome.mjs` 의 `withTab('naver', ...)` 를 부른다.
  2. 받는사람: `#recipient_input_element` 입력 후 `Enter` (`#sender_input` 은 숨은 레이어에 있으므로 건드리지 않는다).
  3. 제목: `#subject_title` 입력.
  4. 첨부: `#ATTACH_LOCAL_FILE_ELEMENT_ID` 에 `setInputFiles([pdfPath.normalize('NFC'), zipPath.normalize('NFC')])` 로 넣고 5초 대기한다. 첨부 목록 UI 가 파일명과 확장자(`.pdf`, `.zip`)를 별도 칸으로 나누어 그리므로 검증 시 `(document.body.innerText).normalize('NFC')` 에서 확장자를 뺀 파일 베이스명으로 확인한다.
  5. 본문: 자식 프레임(`page.frames()`)의 `[contenteditable="true"]` 에 HTML 을 넣고 `input` 이벤트를 발생시킨다.
  6. **준비 요청**이면 `button.button_task`('임시저장')만 누르고 멈춘다. **발송 지시**가 있을 때만 `button.button_write_task`('보내기') 클릭 → `/v2/new/done`('메일을 성공적으로 보냈습니다.') 및 보낸메일함(`/v2/folders/1`) 도착까지 확인한 뒤 자기 탭을 닫는다.
