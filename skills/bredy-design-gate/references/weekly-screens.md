# 주간 점검 화면 목록과 기준 앱

화면이 새로 생기거나 없어지면 이 표를 고친다. 앱 경로는 bredy_app `src/app`, 웹은 breeder_web `app/(web)`.

| # | 화면 | 앱 경로(대략) | 기준 앱 장면 |
|---|---|---|---|
| 1 | 홈(파충류·소동물) | (tabs)/index | 당근 홈 목록 |
| 2 | 홈(멍냥) | (tabs)/index 멍냥 모드 | 당근 홈 목록 |
| 3 | 분양글 상세 | products/[id] | 당근 글 상세 |
| 4 | 분양 글쓰기 | products/upload | 당근 글쓰기 |
| 5 | 입양(보호소) 목록 | adoption | 당근 동네 목록 |
| 6 | 반려생활(커뮤니티) 피드 | posts | 인스타 피드 |
| 7 | 생생 영상 줄·세로 보기 | 홈 영상 줄·shorts | 네이버 클립 |
| 8 | 경매 목록·상세 | auctions | 당근 목록 / 요청 시 피들 경매 |
| 9 | 채팅 목록·채팅방 | chats | 당근 채팅 |
| 10 | 마이페이지 | (tabs)/my | 토스 전체 탭 |
| 11 | 프로필 | profiles/[id] | 인스타 프로필 |
| 12 | 설정·언어 변경 | settings | 토스 설정 |
| 13 | 추천템(스토어) | store | 네이버 쇼핑 / 토스 쇼핑 |
| 14 | 동네 지도 | map | 당근 지도 |
| 15 | 무지개 마을·추모관 | village | 요청 시 별꾹 |
| 16 | 알림 | notifications | 인스타 알림 |
| 17 | 로그인·가입 | auth | 토스 로그인 |
| 18 | 검색 | search | 네이버 검색 |

빈 상태가 있는 화면은 빈 상태도 한 장 찍는다(새 계정·필터 결과 0).
