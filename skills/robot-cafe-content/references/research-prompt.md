# 조사 서브에이전트 요청문

`Agent(subagent_type: general-purpose, model: sonnet)`에 아래를 채워 넘긴다. `{…}`만 바꾼다.

```text
한국 네이버 카페 '로봇천국'의 [오늘의 로봇 뉴스]({오늘 날짜})에 쓸 로봇 뉴스 5~6건을 찾아서, 각 기사를 직접 열어 사실을 검증한 결과만 돌려줘. 결과는 한국어로.

조건
- 기간: {오늘-3일} ~ {오늘} 사이 게재된 기사. 날짜를 기사 페이지에서 확인한다.
- 이미 쓴 기사는 빼라: {history.py used 출력}
- 예비 후보(어제 확인함, 여전히 기간 안이면 써도 됨): {어제 candidates.md}
- 구성: 국내 2건 이상(로봇신문 irobotnews.com, 지디넷코리아, 전자신문, 조선비즈 등), 해외 2~3건(The Robot Report, IEEE Spectrum, TechCrunch, Electrek, DroneXL 등).
- 분야를 섞는다: 휴머노이드, 로봇청소기·가정용, 드론, 서빙·배달, 협동로봇·산업용, 한국 정책·기업·투자. 일반인도 흥미 있을 것 우선. 자극적인 사건·사고, 홍보성 판촉 기사는 빼라.
- 효율: 먼저 목록 페이지(https://www.irobotnews.com/ , https://www.therobotreport.com/ , 지디넷코리아 로봇 기사 검색)를 WebFetch로 열어 후보를 고르고, 고른 기사만 원문을 연다. 도구 호출은 30번 안에서 끝낸다.
- 원문 페이지를 열지 못했거나 날짜를 확인 못한 기사, 뉴스 모음 페이지는 넣지 않는다. Reuters·The Verge·연합뉴스처럼 열리지 않는 곳은 건너뛴다.

각 건마다: 원제목, 매체명, 게재일(YYYY-MM-DD), 원문 URL, 기사에 나온 핵심 사실 2~3개(숫자·이름은 기사 본문 그대로, 문장은 짧게), 왜 재밌는지 한 줄, 검증 메모(회사 주장인지·예정인지·2차 보도인지·실명 주의).
마지막에 JSON 배열: [{"title","media","date","url","facts":[...],"why","note","verified":true}]
확인 못 한 것은 지어내지 말고 빼라.
```

## 정보글(guide) 조사

```text
네이버 카페 '로봇천국'의 [{게시판}] 게시판 정보글 '{주제}'를 쓰려고 한다. 이 주제의 사실을 믿을 만한 출처에서 확인해 줘. 결과는 한국어로.
- 출처 우선순위: 정부·공공기관(국토교통부, 한국교통안전공단, 국립전파연구원, 한국로봇산업진흥원 등), 제조사 공식 페이지, 주요 언론. 블로그·쇼핑몰 광고 글은 쓰지 않는다.
- 숫자·가격·규정·모델명은 원문 페이지를 WebFetch로 열어 확인한 것만. 가격은 확인한 날짜와 기준(공식 판매가 등)을 적는다.
- 도구 호출 25번 안.
돌려줄 것: 핵심 사실 6~10개(사실마다 출처 URL·기관명·확인한 날짜), 틀리기 쉬운 점이나 최근 바뀐 규정, 그리고 JSON 배열 [{"title","media","date","url","facts":[...],"note","verified":true}] (출처마다 한 항목).
```

## 채용 모음(jobs) 조사

```text
로봇 분야 채용 공고 5~8건을 찾아 원문을 열어 확인해 줘(오늘 {날짜} 기준 마감 전인 것만). 결과는 한국어로.
- 찾을 곳: 한국로봇산업진흥원 채용(https://www.kiria.org/portal/info/portalInfoJobList.do), 로봇 회사 공식 채용 페이지(레인보우로보틱스, 두산로보틱스, 로보티즈, 뉴로메카, 클로봇 등), 사람인·원티드·잡코리아의 공개 공고.
- 이미 쓴 공고는 빼라: {history.py used 출력}
- 공고마다: 회사명, 직무, 신입·경력 조건, 근무지, 마감일, 원문 URL, 무슨 일을 하는 자리인지 한 줄. 마감일을 확인 못 하면 '상시'라고 적되 원문에 상시라고 있을 때만.
- 도구 호출 30번 안. JSON 배열 [{"title","media":"회사명","date":"마감일","url","facts":[...],"verified":true}]
```

## 행사 일정(events) 조사

```text
앞으로 2주({날짜}~{날짜+14일}) 안에 열리는 국내 로봇·드론·자동화 관련 전시회·박람회·세미나·체험 행사를 찾아 공식 안내 페이지로 확인해 줘. 결과는 한국어로.
- 행사마다: 행사명, 기간, 장소, 참가비·사전 등록 여부, 공식 안내 URL, 한 줄 소개.
- 날짜가 확정되지 않았거나 공식 페이지가 없는 행사는 빼라. 도구 호출 25번 안.
- JSON 배열 [{"title","media":"주최","date":"시작일","url","facts":[...],"verified":true}]
```
