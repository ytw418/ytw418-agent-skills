# 조사 서브에이전트 요청문

`Agent(subagent_type: general-purpose, model: sonnet)`에 아래를 채워 넘긴다. `{…}`만 바꾼다.

```text
한국 네이버 카페 '로봇천국'의 [오늘의 로봇 뉴스]({오늘 날짜})에 쓸 로봇 뉴스 5~6건을 찾아서, 각 기사를 직접 열어 사실을 검증한 결과만 돌려줘. 결과는 한국어로.

조건
- 기간: {오늘-3일} ~ {오늘} 사이 게재된 기사. 날짜를 기사 페이지에서 확인한다.
- 이미 쓴 기사는 빼라: {history.py used 출력}
- 예비 후보(어제 확인함, 여전히 기간 안이면 써도 됨): {어제 candidates.md}
- 구성: 국내 2건 이상(로봇신문 irobotnews.com, 지디넷코리아, 전자신문, 조선비즈 등), 해외 2~3건(The Robot Report, IEEE Spectrum, TechCrunch, Electrek, DroneXL 등).
- 분야를 섞는다: 휴머노이드, 로봇청소기·가정용, 드론, 서빙·배달, 협동로봇·산업용, 한국 정책·기업·투자. 일반인도 흥미 있을 것 우선. 자극적인 사건·사고, 홍보성 판촉 기사는 빼라.
- 효율: 먼저 목록 페이지(https://www.irobotnews.com/ , https://www.therobotreport.com/ , 지디넷코리아 로봇 기사 검색)를 WebFetch로 열어 후보를 고르고, 고른 기사만 원문을 연다. 도구 호출은 30번 안에서 끝낸다.
- 원문 페이지를 열지 못했거나 날짜를 확인 못한 기사, 뉴스 모음 페이지는 넣지 않는다. Reuters·The Verge·연합뉴스처럼 열리지 않는 곳은 건너뛴다.

각 건마다: 원제목, 매체명, 게재일(YYYY-MM-DD), 원문 URL, 기사에 나온 핵심 사실 2~3개(숫자·이름은 기사 본문 그대로, 문장은 짧게), 왜 재밌는지 한 줄, 검증 메모(회사 주장인지·예정인지·2차 보도인지·실명 주의).
마지막에 JSON 배열: [{"title","media","date","url","facts":[...],"why","note","verified":true}]
확인 못 한 것은 지어내지 말고 빼라.
```
