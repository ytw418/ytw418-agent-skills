# 브리디 인스타 DM 영업

상세 기획: `references/prd.md`. 문구: `references/templates.md`. 브라우저 다루는 법(꼭 읽기): `references/browser-recipe.md`.

```bash
OUT=~/.claude/skills/bredy-instagram-outreach/scripts/outreach.mjs   # 데이터: ~/Documents/bredy-outreach
node $OUT slots        # 남은 창립 브리더 자리
node $OUT stats        # 상태별 수, 오늘 보낸 수(한도 20)
node $OUT next 7       # 이번에 보낼 후보(handle 닉네임 분야 유형)
node $OUT mark <handle> 보냄|답장|관심|가입|거절|제외 "메모"
node $OUT add <handle> <닉네임> <분야> <유형> <출처> "메모"
```

## 전제 (하나라도 아니면 보내지 않는다)

1. Paseo 앱이 켜져 있고 브라우저 패널에 instagram.com 탭이 **화면에 보이는 상태**(스크린샷 성공). 가려지면 클릭·전송이 실패한다.
2. 그 탭에 **bredy_breeder 로 로그인**돼 있다. 로그인은 사용자가 브라우저에서 직접 한다. 비밀번호·토큰은 받지 않는다. 로그인 쿠키가 남아 있는 동안은 다음 실행도 그대로 된다.
3. `~/Documents/bredy-outreach/targets.csv` 가 있다(없으면 `add` 로 만든다).

## 실행 순서 (한 번 = 아침/점심/저녁 한 슬롯)

1. **준비 확인** — browser-recipe '먼저 확인' 1~4. 실패하면 이유를 적고 끝낸다.
2. **남은 자리** — `node $OUT slots` 값을 이번 실행 문구의 `{남은자리}` 로 쓴다. 0이면 보내지 말고 사용자에게 묻는다.
3. **답장 정리** — DM함 Unread 를 연다. templates.md '자동으로 보내도 되는 것' 표에 맞으면 그 답을 보내고 `mark`. 표 밖이면 답하지 말고 보고의 '사람에게 넘길 것'에 `닉네임 — 받은 말 요약`을 적는다. 사용자가 직접 대화 중인 사람은 건드리지 않는다.
4. **새 메시지** — `node $OUT next 7` 순서대로 browser-recipe '새 사람에게 보내기' 1~8. 유형별 문구(templates.md)에 닉네임만 넣는다. 프로필을 따로 조사하지 않는다(토큰 절약).
5. **목록 보충** — 후보가 7명 미만이면 팔로워 → 팔로잉 → 홈 추천(관련 계정만 팔로우, 실행당 5명 이하) → 해시태그 순으로 `add`. 해외·무관·지인 계정은 `제외`/`확인필요`.
6. **보고** — `~/Documents/bredy-outreach/log/<YYYY-MM-DD>.md` 에 덧붙이고 답변에도 쓴다:
   - 사람에게 넘길 것(맨 위) / 답장 온 사람·처리 / 이번에 보낸 수·오늘 누계 / 가입 / 남은 자리 / 다음 후보 수

## 지키는 것

- 새 메시지는 실행당 7명, 하루 20명 이하. 같은 사람에게 첫 메시지는 한 번. 무응답에 재촉하지 않는다. 거절하면 끝.
- 약속은 PRD 5장에 있는 것만(창립 브리더·수수료 평생 0원, 샵·행사 베타 배너·팝업). 분양글 상단 노출·인증 뱃지·금전 보상은 약속하지 않는다.
- '상품·판매·구매' 대신 '분양글·분양·입양'.
- AI 여부를 물으면 솔직하게 답하고 사람에게 넘긴다.
- 차단 회피 위장(일부러 넣는 무작위 지연, 다계정, 탐지 우회 도구)은 쓰지 않는다. 인스타가 제한 경고를 띄우면 그날 중단하고 알린다.
- targets.csv·로그는 저장소에 커밋하지 않는다(다른 사람 계정 정보).
