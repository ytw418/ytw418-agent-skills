# PRD — 브리디 인스타 DM 영업 (bredy-instagram-outreach)

- 작성: 2026-10-10 · 상태: 운영 중(1일차 진행) · 담당: 브리디 운영자(사용자) + Claude(실행)
- 관련: 브리디 킥 가설(곤충·물고기 경매), 창립 브리더 프로그램(웹 `libs/shared/breeder-program.ts`)

## 1. 목적

인스타그램에서 크레스티드게코·파충류·곤충·물고기를 분양하는 브리더·샵·키우는 사람에게 브리디 공식 계정으로 1:1 DM 을 보내 **가입**과 **첫 활동(분양글·사진·혈통)**을 끌어낸다. 정식 출시(앱 출시 한 달 뒤) 전 베타 기간 안에 창립 브리더 100자리를 채우는 것이 1차 목표다.

## 2. 배경

- 10-09 사용자가 손으로 같은 홍보 문구를 여러 명에게 보냈다(참크레·맑지·김푸치 등). 답장 몇 건이 왔고 그중 드링크레가 웹으로 들어가겠다고 했다.
- 10-10 이 스킬로 전환. 첫날 프로필을 하나씩 보고 맞춤 문구를 쓰다가, 토큰이 많이 들어 **닉네임 + 유형별 공통 문구**로 바꿨다(사용자 결정).
- 10-10 기준 창립 브리더 29/100(남은 71). 루기아(이색동물 콘텐츠 제작자)가 DM 직후 가입.
- 10-10 1일차: 팔로워 중 20명(브리더 13·키우는 분 5·샵 1·행사 1)에게 발송, 답장 2건(드링크레·루기아) 처리.
- 10-10 문구 개정(사용자): 혈통 카드·반려생활 대신 분양글·무료 경매·운영자가 대신 광고·초기 등록 상위 노출을 앞에 두고, 첫 메시지에 웹 링크를 넣는다.

## 3. 범위

| 포함 | 제외 |
|---|---|
| 브리디 공식 계정(bredy_breeder) DM 발송·답장 | 사용자 개인 계정 사용 |
| 대상 수집(팔로워·팔로잉·홈 추천·해시태그) | 여러 계정 돌리기, 차단 회피 위장 |
| 대상·상태 기록(targets.csv), 남은 창립 브리더 자리 확인 | 브리디 서버 DB 직접 조회·수정 |
| 정해진 시간 자동 실행(Paseo 일정) | 댓글·좋아요 자동화(이번 범위 밖) |

## 4. 대상과 유형

| 유형 | 예 | 메시지 핵심 |
|---|---|---|
| 브리더 | 크레 브리더(꾹크레·헤르츠) | 분양글·경매 무료 + 대신 광고 + 초기 상위 노출 + 수수료 평생 0원 |
| 키우는분 | 반려 1~6마리 기록 계정(대파·매달이) | 브리더와 같은 문구(10-10 개정) |
| 샵 | 파충류샵(팀콜벳·킹크레) | 매장 개체 분양 + 베타 기간 상단 배너·팝업 무료 |
| 행사 | 충인 체육대회 | 행사 소식 배너·팝업 무료 |
| 콘텐츠 | 루기아 | 반려생활 글 — 개별 대응(자동 문구 없음, 사람이 판단) |

찾는 순서: ① 공식 계정 팔로워 → 팔로잉 ② 홈 피드 추천 유저(관련 계정만 팔로우 후 DM) ③ 해시태그(#크레스티드게코분양 #장수풍뎅이분양 #사슴벌레분양 #구피분양 #베타분양). 해외 계정·무관 계정·사용자 지인은 제외, 애매하면 `확인필요`.

## 5. 혜택(약속해도 되는 것만)

- 창립 브리더: 가입 선착순 100명에게 자동 부여, 전용 프레임·뱃지 + **경매 수수료 평생 0원**. 남은 자리는 `https://bredy.app/content/breeder-program` 숫자로 매 실행 확인.
- **상생 홍보**(10-10 사용자 결정): 브리디에 분양글·경매글을 올리면 운영자가 그 개체를 인스타·유튜브·스레드 광고와 바이럴로 돌린다 → 보고 들어온 사람이 그 브리더 프로필·SNS 링크까지 간다. 시기·횟수는 약속하지 않는다.
- 샵·행사: 가입해서 활동하면 **베타 기간 동안 상단 배너·팝업 무료**(운영자가 관리자 배너로 직접 올린다).
- **초기 등록 상위 노출**(10-10 사용자 결정): 초기에 등록한 브리더의 분양글을 운영자가 위에 올려 준다. 앱엔 아직 자동 기능이 없고 DB `Product.isFeatured`(쓰이지 않는 칸)만 있다 → 운영자 수동 또는 기능 개발 필요. 기간·순서는 약속하지 않는다.
- **무료 경매·분양글**: 분양글·경매 등록은 무료, 창립 브리더는 경매 수수료 평생 0원.
- 하지 않는 약속: 인증 브리더 뱃지(10-09 손 DM 에 있었으나 지금 정책 아님 — 물어보면 사람에게 넘긴다), 금전 보상, 광고 시기·횟수.

## 6. 흐름

### 6.1 한 번 실행(run)
1. 준비 확인: Paseo 브라우저 탭 존재 → 화면 그려짐(스크린샷 성공) → bredy_breeder 로그인. 하나라도 실패하면 아무것도 보내지 않고 알린다.
2. `slots` 로 남은 자리 확인.
3. **답장 처리**: DM함 Unread 를 위에서부터 연다 → 템플릿 표에 맞으면 자동 답장 + 상태 기록, 아니면 `사람에게 넘길 것` 목록에 요약만 적고 답하지 않는다.
4. **새 메시지**: `next 7`(하루 20 한도 안) → 사람마다 browser-recipe 순서로 이전 대화 확인 → 유형별 문구에 닉네임·남은 자리 넣어 전송 → `mark 보냄`.
5. 후보가 7명 미만이면 4장 순서대로 목록을 보충(`add`)한다. 보충만 하고 그 실행에서 다 못 보낸 사람은 다음 실행으로 넘긴다.
6. 보고: 오늘 보낸 수, 답장 온 사람과 내용 요약, 사람에게 넘길 대화, 가입 수, 남은 자리 → `~/Documents/bredy-outreach/log/<날짜>.md` 에 덧붙이고 답변으로도 낸다.

### 6.2 일정 (10-10 등록)
- Paseo 일정 3회/일: 09:00 · 13:00 · 19:00 (KST, cron `0 9,13,19 * * *`). 실행마다 6.1 전체.
- 하루 새 메시지 20명(실행당 최대 7). 답장은 한도 없음.
- 사람에게 넘길 대화가 생기면 보고 맨 위에 둔다.

## 7. 규칙

- 같은 사람에게 첫 메시지는 한 번만. 무응답이면 다시 보내지 않는다. 거절하면 `거절` 기록 후 끝.
- 화면 용어: 상품·판매·구매 → 분양글·분양·입양.
- AI 여부를 물으면 숨기지 않는다.
- 인스타가 제한 경고를 띄우면 그날 중단.
- 다른 사람 계정 정보(targets.csv·로그)는 저장소에 커밋하지 않는다. 데이터는 `~/Documents/bredy-outreach/` 에만 둔다.
- 비밀번호·세션 토큰을 묻거나 저장하지 않는다. 로그인은 사용자가 브라우저에서 직접 한다.

## 8. 데이터

`~/Documents/bredy-outreach/`
- `targets.csv`: `handle,닉네임,분야,유형,출처,보낸날,상태,메모`. 상태: 후보·보냄·답장·관심·가입·거절·무응답·확인필요·제외·보류.

## 9. 오류·예외

| 상황 | 처리 |
|---|---|
| 스크린샷 `not painted` | Paseo 브라우저 패널이 가려진 것 — 문제없다. 첫 줄을 ref 로 입력하는 방법으로 보낸다(browser-recipe 3) |
| 로그인 화면·다른 계정 | 중단, 사용자에게 로그인·전환 요청 |
| 전송 확인 실패 | 스냅샷으로 말풍선·입력창 확인 후 보내기 버튼만 다시 누름. 재타이핑 금지 |
| 대화방에 이전 영업 메시지 | 보내지 않고 `제외 "기존 대화"` |
| 계정 없음(페이지 삭제) | `제외 "계정 없음"` |
| 인스타 제한 경고 | 그날 중단, 알림 |
| 남은 자리 0 | 창립 브리더 문장을 빼고 보내기 전에 사용자에게 새 혜택을 묻는다 |

## 10. 수용 기준(AC)

- AC1 준비 확인 셋 중 하나라도 실패하면 메시지가 0건 나간다.
- AC2 한 실행에서 새 메시지는 7건 이하, 하루 20건 이하다(`stats.sentToday`).
- AC3 보낸 모든 사람이 targets.csv 에 `보냄` 이상 상태와 보낸 날짜로 남는다.
- AC4 같은 handle 로 첫 메시지가 두 번 나가지 않는다.
- AC5 메시지의 남은 자리 숫자가 그 실행의 `slots` 값과 같다.
- AC6 템플릿 표 밖 질문에는 자동 답장이 나가지 않고 보고의 '사람에게 넘길 것'에 남는다.
- AC7 메시지에 '상품·판매·구매'가 없다.

## 11. 위험

- 인스타 약관은 자동화 DM 을 금지한다. 많이·같은 문구로 보내면 메시지 요청함으로 빠지거나 공식 계정이 제한될 수 있다 → 하루 20명, 유형별 문구 + 닉네임, 제한 경고 시 즉시 중단.
- 정보통신망법 50조(광고성 정보 사전 동의) 위반 소지 → 1:1·소량, 거절 즉시 중단, 다시 보내지 않음.
- Mac 잠자기·Paseo 종료·로그아웃이면 일정이 돌지 않거나 첫 단계에서 멈춘다 → 보고로 알린다.

## 12. 남은 결정

- 홈 추천 유저 자동 팔로우 허용 범위(제안: 실행당 5명 이하).
- 루기아 같은 콘텐츠 제작자에게도 배너·팝업 제안을 할지.
