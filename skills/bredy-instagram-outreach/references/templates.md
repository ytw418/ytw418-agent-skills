# 메시지 틀

- `{닉네임}`: 대화방 머리글의 표시 이름(꾸밈 기호·괄호 설명은 뺀다. 예: `𓊆윤이콘𓊇` → 윤이콘, `대파(대단한파충류)` → 대파). 없으면 "안녕하세요!"로 시작한다.
- `{남은자리}`: `node $OUT slots`. 실행마다 한 번 확인.
- 화면 용어: '상품·판매·구매'를 쓰지 않는다 → 분양글·분양·입양.
- 첫 메시지엔 링크를 넣지 않는다(관심 있다고 하면 보낸다). 줄바꿈은 Shift+Enter.
- 프로필을 따로 조사하지 않는다(토큰 절약, 2026-10-10 사용자 결정). 닉네임과 유형만 바꿔 넣는다.
- **상생 제안**(2026-10-10 사용자 결정): 브리디에 분양글·경매글을 올리면 운영자가 그 개체를 인스타·유튜브(스레드) 광고와 바이럴로 돌린다 → 보고 들어온 사람이 그분 프로필과 프로필 링크(SNS)까지 간다 → 서로 홍보 효과.

## 답장 — 말투

사용자가 직접 답한 대화(드링크레·루기아, 2026-10-09~10)를 따른다.
- 짧게, 존댓말에 "ㅎㅎ", "넵", "네넴". 긴 설명은 2~3줄로 끊는다.
- 1인 개발자라는 점을 솔직하게 말한다. 과장하지 않는다.

## FAQ — 사실만 답한다

- 수수료: 창립 브리더(가입 선착순 100명, 자동)는 경매 수수료 평생 0원.
- 유료냐: 가입·분양글·반려생활 글은 무료.
- 앱: Android 앱 출시 준비 중. 지금은 웹(https://bredy.app)으로 쓰고 홈 화면에 설치할 수 있다.
- 정식 출시: 앱 출시 한 달 뒤. 그 전까지가 베타 기간.
- 배너·팝업: 샵·행사 계정이 가입해서 활동하면 베타 기간 동안 무료로 띄워 준다(운영자가 직접 올린다). 상단 배너 광고는 기획 중.
- 광고 홍보: 올라온 분양글·경매글 개체를 운영자가 인스타·유튜브·스레드 광고·바이럴로 돌린다. 언제·얼마나 돌릴지는 약속하지 않는다.
- 분양글 상단 노출(앱 기능): 없음 — 약속하지 않는다.
